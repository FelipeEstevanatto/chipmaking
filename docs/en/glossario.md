# Glossary

| Term | Meaning | Chapter |
|------|---------|---------|
| **HPQ** | High-purity quartz | [Mining](/en/mineracao-mg-si) |
| **MG-Si** | Metallurgical-grade silicon (~98–99.5% Si) | [Mining](/en/mineracao-mg-si) |
| **TCS** | Trichlorosilane (SiHCl₃), gaseous intermediate | [Polysilicon](/en/polissilicio) |
| **SoG-Si** | Solar-grade polysilicon (7N–9N) | [Polysilicon](/en/polissilicio) |
| **EG-Si** | Electronic-grade polysilicon (10N–11N) | [Polysilicon](/en/polissilicio) |
| **CVD** | Chemical vapour deposition (e.g. the Siemens process) | [Polysilicon](/en/polissilicio) |
| **FBR** | Fluidized bed reactor for polysilicon | [Polysilicon](/en/polissilicio) |
| **CZ** | Czochralski growth of a monocrystalline ingot | [Wafer fabrication](/en/fabricacao-wafers) |
| **DWS** | Diamond wire slicing | [Wafer fabrication](/en/fabricacao-wafers) |
| **CMP** | Chemical-mechanical polishing | [Wafer fabrication](/en/fabricacao-wafers) |
| **RCA** | Standardised SC-1 / SC-2 wafer cleaning | [Wafer fabrication](/en/fabricacao-wafers) |
| **Miller** | Notation for crystallographic planes and directions | [Crystal structure](/en/estrutura-wafers) |
| **DUV / EUV** | Deep (193 nm) and extreme (13.5 nm) ultraviolet | [Photolithography](/en/fotolitografia) |
| **HKMG** | Metal gate + high-K dielectric | [Transistors](/en/transistores) |
| **FinFET** | 3D fin transistor (three-sided gate) | [Transistors](/en/transistores) |
| **GAAFET** | Gate-all-around nanosheet transistor | [Transistors](/en/transistores) |
| **BSPDN** | Backside power delivery network | [Transistors](/en/transistores) |
| **CFET** | Vertically stacked NFET/PFET | [Transistors](/en/transistores) |
| **TSV** | Through-silicon via | [Transistors](/en/transistores) |
