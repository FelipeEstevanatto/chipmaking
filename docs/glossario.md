# Glossário

| Termo | Significado | Capítulo |
|-------|-------------|----------|
| **HPQ** | Quartzo de alta pureza (*high-purity quartz*) | [Mineração](/mineracao-mg-si) |
| **MG-Si** | Silício grau metalúrgico (~98–99,5% Si) | [Mineração](/mineracao-mg-si) |
| **TCS** | Triclorossilano (SiHCl₃), intermediário gaseoso | [Polissilício](/polissilicio) |
| **SoG-Si** | Polissilício grau solar (7N–9N) | [Polissilício](/polissilicio) |
| **EG-Si** | Polissilício grau eletrônico (10N–11N) | [Polissilício](/polissilicio) |
| **CVD** | Deposição química de vapor (ex.: processo Siemens) | [Polissilício](/polissilicio) |
| **FBR** | Reator de leito fluidizado para polissilício | [Polissilício](/polissilicio) |
| **CZ** | Crescimento Czochralski de lingote monocristalino | [Fabricação de wafers](/fabricacao-wafers) |
| **DWS** | Corte por fio diamantado (*diamond wire slicing*) | [Fabricação de wafers](/fabricacao-wafers) |
| **CMP** | Polimento químico-mecânico | [Fabricação de wafers](/fabricacao-wafers) |
| **RCA** | Limpeza SC-1 / SC-2 padronizada em wafers | [Fabricação de wafers](/fabricacao-wafers) |
| **Miller** | Notação de planos e direções cristalográficas | [Estrutura e tipos](/estrutura-wafers) |
| **DUV / EUV** | Ultravioleta profundo (193 nm) e extremo (13,5 nm) | [Fotolitografia](/fotolitografia) |
| **HKMG** | Portão metal + dielétrico High-K | [Transistores](/transistores) |
| **FinFET** | Transistor de aleta 3D (portão tri-lateral) | [Transistores](/transistores) |
| **GAAFET** | Portão em torno de nanofolhas (*gate-all-around*) | [Transistores](/transistores) |
| **BSPDN** | Rede de alimentação no verso do die (*backside power*) | [Transistores](/transistores) |
| **CFET** | NFET/PFET empilhados verticalmente | [Transistores](/transistores) |
| **TSV** | Via de silício passante (*through-silicon via*) | [Transistores](/transistores) |
